# Vrykell

**Your terminal, your tools, your AI — together.**

A desktop workspace for development and remote operations, built around the terminal.

<p align="center"><sub>Code, run commands, and work with an agent in the same workspace.</sub></p>

---

Work with **local shells and SSH**, browse files, edit code, review Git changes, and bring your own model or external agent. Arrange the tools you need side by side, with up to four panes per tab.

Vrykell is in beta for Windows, macOS, and Linux. See the [project README](https://github.com/Vrykell/Vrykell#readme) for platform requirements and current limitations.
